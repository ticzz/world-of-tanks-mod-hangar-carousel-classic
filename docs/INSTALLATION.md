# Hangar Carousel Classic 1.0.11

Hangar Carousel Classic restores and extends the classic World of Tanks hangar carousel with native Gameface integration, configurable filters, hierarchical sorting, and vehicle-card statistics.

## Compatibility and dependencies

- World of Tanks `2.4.0.0` or a compatible client.
- `net.openwg.gameface` is required for the carousel interface.
- Aslain's Mod Menu is optional. It provides the in-game settings panel for carousel rows, filtering, sorting, card statistics, and action cards.
- `aslain.modssettingsbridge` is required together with Aslain's Mod Menu.

## Full package (recommended)

1. Download [hangar_carousel_classic_1.0.11_full.zip](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.11/hangar_carousel_classic_1.0.11_full.zip).
2. Extract the archive into the World of Tanks installation directory.
3. Confirm that the files are located under `mods/2.4.0.0/`.
4. Start the game.

The full package contains:

- `mod_hangar_carousel_classic_1.0.11.wotmod`
- `aslain.modmenu_2.0.07.wotmod`
- `aslain.modssettingsbridge_1.0.2.wotmod`
- `net.openwg/net.openwg.gameface_1.1.6.wotmod`

## HCC-only installation

1. Download [mod_hangar_carousel_classic_1.0.11.wotmod](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.11/mod_hangar_carousel_classic_1.0.11.wotmod).
2. Copy it to the client's `mods/2.4.0.0/` directory.
3. Install the matching `net.openwg.gameface_*.wotmod` from the [OpenWG Gameface releases](https://gitlab.com/openwg/wot.gameface/-/releases) in the same directory.

Without Mod Menu, HCC remains functional through the native carousel filter panel. To use the in-game HCC settings panel, install both Aslain's Mod Menu and its matching ModsSettingsBridge.

## Features

- Classic carousel layout with 1 to 4 rows and automatic row mode.
- Vehicle-card statistics for battles, win rate, average damage, alpha damage, mastery, and Marks of Excellence.
- Native filters with combined AND logic.
- Hierarchical sorting with ascending or descending criteria.
- Custom nation and vehicle-type priority ordering.
- Optional hiding of buy vehicle, buy slot, and restore vehicle cards.
