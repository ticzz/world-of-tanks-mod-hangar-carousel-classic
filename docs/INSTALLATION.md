# Installation

Version `1.0.23` targets WoT `2.4.1.1`; the native bundle hashes and package paths were verified against the installed client. The full package includes OpenWG GameFace `1.2.2`, which is required for the carousel UI. The in-game hangar smoke test has not yet been performed.

## Full package (recommended)

[Download the v1.0.23 ZIP](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.23/hangar_carousel_classic_1.0.23_full.zip) and extract it into the WoT root directory for WoT `2.4.1.1`. It contains the mod and OpenWG GameFace `1.2.2`. Aslain's Mod Menu and ModsSettingsBridge are not bundled; get or update them separately via [Aslain's WoT ModPack](https://aslain.com/index.php?/topic/13-download-%E2%98%85-world-of-tanks-%E2%98%85-modpack/) if needed.

## HCC only

[Download the v1.0.23 WOTMOD](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.23/mod_hangar_carousel_classic_1.0.23.wotmod) and copy it to `mods/2.4.1.1/`. Also install `net.openwg.gameface_1.2.2.wotmod` or newer in that folder from the [OpenWG releases](https://gitlab.com/openwg/wot.gameface/-/releases).

Without Mod Menu and ModsSettingsBridge, HCC remains usable through the native carousel filter panel.
