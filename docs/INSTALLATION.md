# Installation

World of Tanks `2.4.0.0` or a compatible client is required. `net.openwg.gameface` is required for the carousel.

## Full package (recommended)

[Download the ZIP](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.13/hangar_carousel_classic_1.0.13_full.zip) and extract it into the WoT root directory. It includes HCC, Aslain's Mod Menu, ModsSettingsBridge, and GameFace for `mods/2.4.0.0/`.

## HCC only

[Download the WOTMOD](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.13/mod_hangar_carousel_classic_1.0.13.wotmod) and copy it to `mods/2.4.0.0/`. Also install the matching `net.openwg.gameface_*.wotmod` from the [OpenWG releases](https://gitlab.com/openwg/wot.gameface/-/releases).

Without Mod Menu and ModsSettingsBridge, HCC remains usable through the native carousel filter panel.
